# project-castles
personal project site for stardance
An Old School RuneScape (OSRS) themed personal portfolio and web page styled after the classic RuneScape interface layout.

## Features
* **Classic OSRS Layout**: Features a centered 1800px frame layout with authentic repeating vine pillar backgrounds and a solid black border for wide-screen monitors.
* **Custom Navigation Sidebar**: Styled navigation fieldset boxes (`Game`, `Community`, and `Account`) complete with gold headers, icons, and bright green interactive link text.
* **Live Player Counter**: Includes dynamic simulation code to update the active player count in real time beneath the header logo.
* **Responsive Grid Structure**: Built using modern CSS Grid to keep sidebars and main content organized cleanly without overlapping background elements.
* **Custom Typography Support**: Prepared for custom pixel fonts using the `@font-face` rule.
* **Screenshot Gallery**: Fixed-dimension image gallery row positioned cleanly below the welcome container.
